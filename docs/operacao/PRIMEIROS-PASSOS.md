# Validação da primeira entrega

1. Confirmar raiz do repositório com `git status` e `git remote -v`.
2. Extrair arquivos sem apagar `.git` ou arquivos locais existentes; revisar conflitos antes de sobrescrever.
3. Executar `npm install` e registrar versões com `node --version`, `npm --version` e `npm ls --depth=0`.
4. Executar `npm run typecheck` e `npm run build`. Se falhar, não presumir que a entrega está validada.
5. Executar `npm run dev`; revisar navegação e adaptação da interface no navegador.
6. Verificar alterações no GitHub Desktop e publicar primeiro commit com o lockfile gerado.
7. Compartilhar o resultado para revisão.

Não conectar banco nem abrir firewall nesta etapa. O acesso de rede será configurado depois da autenticação. Backups ainda não estão configurados.
